# ⚡ Kuku Tag Bot

Premium Telegram tagging bot with neon themes, fonts, welcome cards and owner tools.

## Features
- /all, /admins, /anybody, /gmtag, /gntag, /vctag, /tagall, /stop
- Settings menu: tag style, per message, limit, font, theme, access
- Welcome and left messages
- Owner and sudo commands

## Setup
1. Create a bot with @BotFather and disable privacy.
2. Get API_ID and API_HASH from my.telegram.org.
3. Deploy this repo on Railway.
4. Add these Variables in Railway:
   BOT_TOKEN, API_ID, API_HASH, OWNER_ID, MONGO_URL, DB_NAME, LOG_GROUP_ID

## Start command
python main.py
